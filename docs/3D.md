# Vista 3D

### Misc:

- Esta parte del proyecto utiliza el framework "three.js" para producir objetos y interacciones 3D.
- Esta preparado para ser montado sobre cualquier parte de la página como modal


### Componentes:

- Scene y Camera son exactamente lo que suenan.
- Renderer se encarga de renderizar la escena.
- Este proyecto utiliza OrbitControls, los cuales funcionan como vista de primera persona con una camara posicionada en 0, 0, 0.
- El programa carga un archivo jpg y lo carga sobre una esfera. Esto actua como skybox.
- De momento estamos utilizando a testbird como placeholder para los sensores, ya decidiremos que sprite utilizar.
- 6 planos componen una caja (de momento transparente, a finales invisible) utilizada para posicionar los sensores.
- El programa lanza un rayo invisible cada vez que se hace click, su interseccion con objetos es utilizado para interactuar con la escena.


### Funcionalidad:

- La vista se mueve arrastrando.
- Doble click crea objetos.
- Click sobre un objeto ejecuta una interaccion (De momento solo de prueba).
